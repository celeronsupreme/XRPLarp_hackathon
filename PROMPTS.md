# Prompts and AI conversations: XRPLarp

All prompts we used are in the shared conversations below. Each link opens the full conversation (our prompts and the assistant's replies) in order. Together these are our prompt set, as required by the hackathon terms (clause 3.3).

**Models and providers:** Claude Fable and Claude Opus 5.5 (Anthropic), used through the claude.ai app; GPT Astra (OpenAI), used through chatgpt.com.
**Settings:** default app settings; no fine-tuning, no custom system prompts, no API use.
**Reproducibility:** LLM output varies from run to run, so re-sending these prompts would not give identical code. The code in this ZIP is the fixed record, and the predictions are reproducible from it without any AI service (see `REPRODUCE.md`).
